# Friday-borns 💬

A simple messaging app built with React. Type a message, hit Send, and it appears as a chat bubble — just like a real messaging app.

## Features

- Type and send messages
- Messages appear as chat bubbles on the right side
- Scrollable message list
- Clean, responsive chat layout

## Tech Stack

- React (useState, component rendering)
- CSS (Flexbox layout)
- Vite (or Create React App)

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- npm
